How to Play

Rules

  • Each row/column needs equal 0s and 1s (2 on 4×4, 3 on 6×6).
  • Never place three identical bits in a line (row or column).
  • Every row must be unique. Every column must be unique.

Controls

  • Green-rim cells are locked clues.

Genius Briefing — NexCorp Kernel

Mission

Crack 8 black-box NX-8 gates. The program is hidden; the ISA is public. Each gate has exactly one key.

How to crack

  • RUN PROBE — send hex bytes into the CPU (example: a7 or 3f 12 90).
  • Output OK means that input is the unique key. NO means keep hunting.
  • On NO for exact-match kernels, the log shows a prefix score: how many leading key bytes are already correct. Lock those, then search the next byte (00–ff).
  • XOR-leak kernels print syndromes as OUT bytes (input⊕key). Probe all 00s → those OUT bytes are the key.
  • Kernels 1–2 also leak registers after probes (secondary hint).
  • SUBMIT KEY only when sure. Wrong submit = 1 strike. 2 strikes lock the link. No Solve.

Kernel map

  • L1 — 1-byte XOR leak. Probe 00.
  • L2 — exact 2 bytes. Prefix score.
  • L3 — exact 3 bytes. Prefix score.
  • L4 — exact 4 bytes. Prefix score.
  • L5 — 2-byte XOR leak. Probe 0000.
  • L6 — exact 4 bytes. Prefix score.
  • L7 — 3-byte XOR leak. Probe 000000.
  • L8 — final exact 4 bytes. Prefix score.

ISA reminder

IN reads your next probe byte into A. OUT emits A. Checkers use XOR, CMP, JZ. Each gate has exactly one key.
