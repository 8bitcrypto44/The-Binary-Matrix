Genius Briefing — NexCorp Kernel

          
Mission

          
Crack 8 black-box NX-8 gates. The program is hidden; the ISA is public. Each gate has exactly one key.

          
How to crack

          
    
            
  • RUN PROBE — send hex bytes into the CPU (example: a7 or 3f 12 90).
    • 
            
  • Output OK means that input is the unique key. NO means keep hunting.
    • 
            
  • On NO for exact-match kernels, the log shows a prefix score.
    • 
            
  • XOR-leak kernels print syndromes as OUT bytes. Probe all 00s → key bytes.
    • 
            
  • SUBMIT KEY when sure. Wrong submit = 1 strike. 2 strikes lock the link.
    • 
          

          
Kernel map

          
    
            
  • L1 — 1-byte XOR leak · L2–L4 exact keys · L5,L7 XOR leaks · L8 final gate
